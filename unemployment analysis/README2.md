# 📊 Unemployment Analysis in India During COVID-19

This data science project analyzes the unemployment rate trends in India, particularly during the COVID-19 pandemic. It includes data preprocessing, visualization, and machine learning for better insights into employment patterns across various Indian states.

---

## 📁 Dataset

Two datasets are used in this project:

1. **Unemployment in India.csv**
2. **Unemployment_Rate_upto_11_2020.csv**

These datasets contain:
- State-wise unemployment data
- Unemployment rates from January to November 2020
- Metrics like Estimated Employed, Labour Participation Rate, and Region

---

## 🎯 Objective

- To analyze the unemployment trends across Indian states.
- To visualize unemployment rate changes before and during the COVID-19 pandemic.
- To draw insights using data science techniques that can be useful for policy makers and researchers.

---

## 🛠️ Tools and Libraries

- **Python**

## 📊 Key Insights

- Visualized unemployment rate changes pre- and post-COVID-19.
- Compared unemployment rates across states.
- Analyzed labour participation rates and employment estimates.
